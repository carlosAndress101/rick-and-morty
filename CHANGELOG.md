# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] — 2026-09-08

### 2026 Modernization Release

A complete modernization of the toolchain, architecture and accessibility of the
application. The user-facing feature set is unchanged — you still browse Rick and Morty
characters page by page — but essentially every line beneath it was rewritten.

This is a major version because the toolchain, the supported Node version and the
project's public module structure all changed in incompatible ways.

---

### Added

- **API transport layer** (`src/api/rickAndMorty.js`) with request timeouts, cancellation,
  HTTP status handling and JSON parsing. Every failure mode is normalised into a single
  `ApiError` type carrying a `kind` of `timeout`, `network`, `http`, `parse`, `validation`
  or `unknown`.
- **Domain service layer** (`src/services/charactersService.js`) that validates raw API
  payloads and normalises them into UI shapes.
- **`useCharacters` hook** — the only place React touches the data path. Returns
  `{ characters, loading, error, pageInfo, status, retry }`.
- **Runtime payload validation** (`src/lib/validations.js`) so malformed third-party data
  cannot surface as a render-time crash deep in the component tree.
- **`ErrorState` component** with a retry button, and an **`ErrorBoundary`** for
  render-time crashes.
- **`EmptyState` component** for successful responses that contain no records.
- **`CharacterSkeleton`** placeholder grid for the first load.
- **`combineSignals()` and `createTimeoutSignal()`** (`src/lib/utils.js`) — cross-browser
  request cancellation primitives built from `AbortController` alone.
- **Environment configuration** via `VITE_API_BASE_URL`, documented in `.env.example`.
- **Developer experience files**: `.editorconfig`, `.gitattributes`,
  `.vscode/extensions.json`, `.vscode/settings.json`, and a `pnpm check` gate that runs
  lint, format and build in one command.
- **`CHANGELOG.md`** (this file).

### Changed

- **React 18.2 → 19.2.** Migrated to named `{ StrictMode }` / `{ createRoot }` imports.
  The app now fails loudly with a clear message if the `#root` element is missing, rather
  than passing `null` into `createRoot`.
- **Vite 4.3 → 8.2** and **@vitejs/plugin-react-swc 3.0 → 4.3**.
- **Bootstrap `5.3.0-alpha3` → `5.3.8`.** The previous release shipped a **pre-release
  alpha** to production.
- **gh-pages 5.0 → 6.3.**
- **Architecture refactored** from four flat files into layered modules with a strict
  one-way dependency rule: `components → hooks → services → api → lib`. No component
  calls `fetch`.
- **Pagination is now dynamic**, derived from the API's `info.pages` metadata. Adds first
  and last page controls and a live page-of-total indicator.
- **Loading experience.** The previous page stays on screen — dimmed and marked
  `aria-busy` — while the next one loads, so page height and scroll position are stable. A
  full skeleton appears only on the genuine first load.
- **Layout uses native CSS Grid** (`auto-fill` / `minmax`) instead of Bootstrap's
  `.row` / `.col-md-4`, so columns respond to available width rather than fixed
  breakpoints.
- **Styling reorganised** into `src/styles/{base,components,utilities}.css` with design
  tokens. Components carry semantic class names instead of long inline utility strings.
- **`vite.config.js` `base`** changed from an absolute `https://carlosAndress101.github.io/…`
  URL to the root-relative `/rick-and-morty/`. Resolves to identical URLs once deployed,
  but `vite dev` and `vite preview` now work locally instead of pointing assets at the
  live github.io host.
- **Build target** is an explicit browser list (`chrome107`, `edge107`, `firefox102`,
  `safari16`) rather than a bare `es2022` level, so the supported matrix is enforced by
  the build rather than asserted in a README.
- **Node requirement** raised to `>= 24`; **pnpm** pinned to `12.3.4` via `packageManager`.
- **Documentation rewritten.** `README.md` created from scratch; `CLAUDE.md` rewritten to
  document architecture, load-bearing rules and deployment.

### Migrated

- **ESLint → Oxlint.** ESLint 8 (end-of-life) and its three plugins were removed
  entirely; there is no `.eslintrc.*`. Configuration lives in `.oxlintrc.json` with the
  `correctness`, `suspicious` and `perf` categories as errors and a zero-warning policy
  (`oxlint --max-warnings=0`).
- **Prettier → oxfmt.** Prettier and its config files were removed; formatting is now
  `oxfmt`, configured in `.oxfmtrc.json` generated by `oxfmt --migrate=prettier`, so the
  style rules are byte-for-byte unchanged. The toolchain is OXC end to end.

### Removed

- **`react-bootstrap`** — a full component library carried for a single `Spinner`.
  Bootstrap's own CSS already ships `.spinner-border`. Removing it also deleted its
  transitive tree: `@restart/ui`, `@restart/hooks`, `dom-helpers`, `prop-types`,
  `uncontrollable`, `warning`, `invariant` and `classnames`.
- **`autoprefixer`** — declared but never invoked; the project has no PostCSS config.
- **`@types/react` and `@types/react-dom`** — TypeScript declarations that contributed
  nothing to a JavaScript-only project's build, lint, format or bundle.
- **`eslint`**, **`eslint-plugin-react`**, **`eslint-plugin-react-hooks`**,
  **`eslint-plugin-react-refresh`**, **`prettier`**.
- **Dead assets and code**: an empty `src/App.css` that was imported twice, an unused
  `src/assets/react.svg`, the default `public/vite.svg`, and an unused `Spinner`
  component.

### Fixed

- **Release blocker: `AbortSignal.any()` incompatibility.** The API layer used
  `AbortSignal.any()`, which is unavailable below Safari 17.4, iOS Safari 17.4,
  Firefox 124 and Chrome 116. Because it is a property read evaluated at request time, it
  threw a `TypeError` **before `fetch` was ever called** — the app failed on affected
  browsers with no network activity and no recoverable error state. Replaced with
  `combineSignals()`, built from `AbortController` alone.
- **`AbortSignal.timeout()` removed.** Beyond lowering the browser floor, its signal
  cannot be cancelled, so the timer kept its callback alive for the full 10 seconds even
  after a request had already succeeded. `createTimeoutSignal()` returns a `cancel()` that
  the request layer calls in a `finally` block.
- **No error handling whatsoever.** The previous code checked neither `response.ok` nor
  caught anything. An offline load produced an unhandled promise rejection and left the
  spinner running forever.
- **Hardcoded pagination limit.** `page >= 42` was a magic number; the page count now
  comes from API metadata.
- **Dead expression on the Prev button** — `props.page < 0 ? props.page === 1 : props.page - 1`
  rendered a stray number next to the label.
- **Unclamped page navigation** — the page setter accepted any number, including
  out-of-range values.
- **Request race conditions.** Requests are now cancelled rather than merely ignored, so a
  slow response for page 1 can never overwrite a fast response for page 2, and no state
  update is attempted after unmount.
- **Cumulative layout shift** from unsized avatar images.

### Accessibility

- Skip link to `#main-content`, plus `banner` / `main` / `contentinfo` landmarks.
- Pagination is a `<nav>` with an accessible name; each button carries an `aria-label`
  naming its destination page, and decorative chevrons are `aria-hidden`.
- **One announcement per event.** A polite `role="status"` region narrates loading and
  completion and falls silent on failure, leaving the error panel's `role="alert"` /
  `aria-live="assertive"` as the only thing that speaks.
- The grid is marked `aria-busy` while a new page loads; skeletons are `aria-hidden`.
- **Heading hierarchy corrected** — a single `<h1>`, character names as `<h2>`, and
  species and origin as text. The previous markup used `<h3>` for data values.
- Descriptive `alt` text on every avatar, plus intrinsic `width` and `height`.
- 3px high-contrast `:focus-visible` ring on all interactive elements.
- Bootstrap button and badge colours re-tuned via CSS variables to clear WCAG AA contrast
  on the dark surface.
- `prefers-reduced-motion` collapses transitions and animations, and switches programmatic
  scrolling from smooth to instant — a CSS media query cannot override the `behavior`
  option of a JavaScript `scrollTo`.

### Browser Compatibility

Minimum supported versions, enforced by `build.target`:

| Browser                  | Minimum   |
| ------------------------ | --------- |
| Chrome                   | 107       |
| Edge                     | 107       |
| Firefox                  | 102 (ESR) |
| Safari                   | 16        |
| iOS Safari               | 16        |
| Android Chromium WebView | 107       |

Safari 16 is the binding constraint.

### Performance

- `react-bootstrap` and its eight-package transitive tree removed.
- `CharacterCard` memoised; the service returns stable character objects.
- Avatars use `loading="lazy"`, `decoding="async"` and intrinsic dimensions.
- `preconnect` and `dns-prefetch` to the API host, so the request begins during JS parse.
- A 10-second timeout on every request, with cancellation on page change and unmount.
- No sourcemaps shipped to production.

### Security & Reliability

- `AbortController` on every request.
- `response.ok` checked; JSON parsing wrapped.
- Runtime shape validation before data reaches React.
- Retry affordance on every failure; `ErrorBoundary` for render-time crashes.
- The API's 404-for-an-out-of-range-page is treated as an ordinary empty result rather
  than an error.
